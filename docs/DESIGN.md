# Design Principles

## UX

1. Mobile first.
2. Segnalare deve richiedere pochi passaggi.
3. Evitare linguaggio burocratico.
4. Stato sempre comprensibile.
5. CTA primaria evidente.
6. Nessun account richiesto.
7. Errori spiegati in modo chiaro.
8. Conferme e duplicati devono essere comprensibili anche a utenti non tecnici.
9. La mappa non deve diventare caotica.
10. Il backoffice deve privilegiare velocità operativa.

## UI

Da definire con l'identità grafica di Visione Comune.

Non inventare palette, font o stile definitivo finché non vengono forniti o deliberati.

## Componenti principali

- header
- hero
- CTA "Segnala un problema"
- form multi-step o guidato
- map view
- report card
- report detail
- status badge
- timeline
- confirmation CTA
- admin table/list
- admin report detail
- alerts
- empty states
